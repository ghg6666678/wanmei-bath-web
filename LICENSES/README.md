# 单独授权记录

`LICENSE` 里提到的那种「另行授予」的许可，记在这里。每条一个文件，命名 `<项目名>.md`。

每个文件至少写清三件事：

- **授权对象**：哪个项目、谁维护、仓库地址
- **授权范围**：允许做什么，明确排除什么
- **时间与形式**：什么时候、通过什么方式（Issue 答复 / 邮件）确认的

单独授权只对该项目有效，不自动扩展到它的衍生版本，也不改变 `LICENSE` 对其他人的效力。

---

## 这些情况不用来问

`LICENSE` 已经明确允许，直接做就行，不需要申请、也不需要登记：

| 情形 | 依据 |
| --- | --- |
| 手机 App 直接连，用户在自己设备上登录自己的账号 | 允许第 2、3 条 |
| 网页 + 反代，只要不落盘、不写进日志、不跨用户共享、一次请求一个会话 | 允许第 4 条 |
| 做给同学用的小工具，非商业 | 允许第 3 条 |
| 引用代码、写文章、做教学，注明出处 | 允许第 5 条 |

其中「网页 + 反代」这条特意写清楚：**浏览器要跨域就得有服务器转发，而 iOS 用户没有客户端可选，只剩网页**。转发不是代登录，不该被同一条款误伤。

## 这些需要来问

- 服务端**持有**票据：写数据库、写配置文件、维持服务端 session
- 带广告、会员、收费、捐赠、引流变现
- 公开发布安装包，或上架应用商店
- 多账号池、批量操作
